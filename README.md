A paper plane breaking out of a torn blueprint toward the viewer, paper shards
flying along a strong diagonal, dark navy background, with the speech bubble:

> "JUDGE! I FLEW HERE FOR YOU!"

The entry is the image `entry.png` (1024x1024, PNG). The program `main.py`
copies it byte-for-byte to `/output/entry.png`.

## How to run

```sh
python3 main.py
```

Output: `/output/entry.png` (identical bytes to `entry.png`).

## Requirements

Python 3, standard library only — no third-party packages.
